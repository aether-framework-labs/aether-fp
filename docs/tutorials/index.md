# Tutorials

Step-by-step guides that walk you through each type in depth. Start from the beginning or jump to the type you need.

## Tutorial List

| Tutorial | Description | Prerequisites |
|----------|-------------|---------------|
| [Working with Either](working-with-either.md) | Every Either method, from creation to extraction | [Sum Types](../concepts/sum-types.md) |
| [Working with Result](working-with-result.md) | Result with error recovery and Either interop | [Either vs Result](../concepts/either-vs-result.md) |
| [Working with Lazy](working-with-lazy.md) | Deferred computation, composition, observation | [Lazy Evaluation](../concepts/lazy-evaluation.md) |
| [Combining Types](combining-types.md) | All three types working together | All individual tutorials |

## Learning Paths

**For beginners:** Either → Result → Lazy → Combining Types

**Error handling focus:** Result → Either → Combining Types

**Performance focus:** Lazy → Combining Types

## Tutorial Format

Each tutorial follows this structure:

1. **Goal** — what you'll build
2. **Prerequisites** — what you need to know
3. **Step-by-step instructions** — with full code at each step
4. **Complete example** — a self-contained working program
5. **Next steps** — where to go from here
