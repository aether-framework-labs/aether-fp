# Examples

Complete, self-contained working examples demonstrating real-world usage patterns.

## Examples

| Example | Types Used | Demonstrates |
|---------|-----------|--------------|
| [Validation Pipeline](validation-pipeline-example.md) | Either | Input validation with flatMap chains |
| [Service Layer](service-layer-example.md) | Result | Exception-free service with typed errors |
| [Configuration Loading](configuration-loading-example.md) | Lazy + Result | Deferred loading with error handling |

## Recommended Order

1. **Validation Pipeline** — shows Either in its natural habitat
2. **Service Layer** — shows Result with sealed error types and pattern matching
3. **Configuration Loading** — shows Lazy and Result working together
